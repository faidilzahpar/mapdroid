                Petunjuk Mudah
                
Panduan Pemasangan Aplikasi

                

                    Pilih platform perangkat Anda untuk melihat panduan langkah demi langkah.
                


                
                

                    
                    
                

            


            
            

                

                    

                        1
                    

                    
Unduh File APK

                    

                        Klik tombol "Unduh untuk Android" di atas. File paket installer Android (.apk) akan tersimpan di perangkat Anda.
                    

                


                

                    

                        2
                    

                    
Izinkan Sumber Luar

                    

                        Jika muncul konfirmasi keamanan, buka Pengaturan > Keamanan & Privasi > Pasang Aplikasi Tidak Dikenal, lalu aktifkan izin untuk browser/file manager.
                    

                


                

                    

                        3
                    

                    
Pasang (Install) APK

                    

                        Buka file .apk melalui bar notifikasi atau dari folder Download pada File Manager Anda, lalu tekan "Install".
                    

                


                

                    

                        4
                    

                    
Mulai Jelajah Peta

                    

                        Jalankan aplikasi MapDroid, berikan izin lokasi (GPS) untuk mendeteksi posisi Anda, dan nikmati penjelajahan peta digital interaktif!
                    

                

            


            
            

                

                    

                        1
                    

                    
Unduh File IPA

                    

                        Klik tombol "Unduh untuk iOS" di atas untuk memperoleh paket berkas aplikasi iOS (.ipa) rilis terbaru.
                    

                


                

                    

                        2
                    

                    
Pilih Alat Sideload

                    

                        Gunakan aplikasi sideloading favorit Anda di iOS atau komputer seperti AltStore, SideStore, Sideloadly, atau TrollStore.
                    

                


                

                    

                        3
                    

                    
Percayai Sertifikat

                    

                        Buka Settings > General > VPN & Device Management di iPhone/iPad Anda, pilih profil akun Apple Anda lalu ketuk "Trust".
                    

                


                

                    

                        4
                    

                    
Buka MapDroid di iOS

                    

                        Buka aplikasi MapDroid di layar utama iPhone/iPad. Nikmati pengalaman peta vektor MapLibre native dengan kontrol yang sama persis seperti versi Android!
                    

                

            

        

    


    
    

        

            

                Keunggulan Lintas Platform
                
Fitur Utama MapDroid

                

                    Konsistensi tampilan dan performa sempurna di Android dan iOS menggunakan arsitektur MapLibre Native.
                

            


            

                
                

                    

                        
                    

                    
MapLibre Native Core

                    

                        Di Android menggunakan MapLibre Android SDK dan di iOS menggunakan MapLibre GL Native via Swift Package Manager dengan performa GPU rendering maksimal.
                    

                


                
                

                    

                        
                    

                    
Kontrol & Posisi Identik

                    

                        Kedua platform memiliki kontrol floating action zoom in, zoom out, tombol reset kamera ke seluruh wilayah kepulauan Indonesia, dan deteksi koordinat saat peta diketuk.
                    

                


                
                

                    

                        
                    

                    
CI/CD Multiplatform

                    

                        GitHub Actions mem-build paket Android APK dan iOS IPA secara paralel otomatis begitu ada perubahan kode, lalu menerbitkan rilis bersamaan.
