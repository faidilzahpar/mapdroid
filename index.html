                Petunjuk Mudah
                
Panduan Pemasangan APK

                

                    Ikuti 4 langkah sederhana berikut untuk menginstal dan menjalankan MapDroid di perangkat Android Anda.
                

            


            

                
                

                    

                        1
                    

                    
Unduh File APK

                    

                        Klik tombol "Unduh APK Sekarang" di halaman ini. File paket installer Android (.apk) akan tersimpan di ponsel Anda.
                    

                


                
                

                    

                        2
                    

                    
Izinkan Sumber Luar

                    

                        Jika muncul peringatan keamanan, buka Pengaturan > Keamanan / Privasi > Pasang Aplikasi Tidak Dikenal, lalu aktifkan izin untuk browser/file manager Anda.
                    

                


                
                

                    

                        3
                    

                    
Pasang (Install) APK

                    

                        Buka file .apk melalui bar notifikasi atau aplikasi File Manager > Download, lalu ketuk tombol "Install".
                    

                


                
                

                    

                        4
                    

                    
Buka Aplikasi & Peta

                    

                        Buka aplikasi MapDroid dari app drawer Anda. Izinkan akses koneksi internet & lokasi untuk mulai menjelajahi peta digital MapLibre secara interaktif!
                    

                

            

        

    


    
    

        

            

                Keunggulan Teknologi
                
Fitur Utama MapDroid

                

                    Dibangun secara modern menggunakan arsitektur open-source untuk performa visualisasi peta terbaik.
                

            


            

                
                

                    

                        
                    

                    
MapLibre Native Android

                    

                        Menggunakan library native C++/OpenGL dari MapLibre yang memberikan rendering peta berbasis vektor secepat kilat dengan konsumsi memori efisien.
                    

                


                
                

                    

                        
                    

                    
Kontrol Kamera Interaktif

                    

                        Dilengkapi kontrol zoom in, zoom out, rotasi gesture multisentuh halus, serta tombol pintasan kembali ke wilayah kepulauan Indonesia.
                    

                


                
                

                    

                        
                    

                    
Otomasi CI/CD & JSCroot

                    

                        Rilis APK otomatis terbit setiap ada pembaruan kode melalui GitHub Actions, dan halaman ini selalu menampilkan info versi terkini menggunakan croot.js.
